⌘DETERMINISTIC

CausePath

causepath

Operator utilities for collecting fingerprints, creating portable incident packets, running exact-match replay gates, sending bounded OTLP batches, and verifying signed proof files.

  • Evidence stays local unless you run an explicit send command.
  • Replay is exact-match only; it does not claim semantic quality or safety.
  • Proof verification checks the signature and content hash locally.
causepath incident init --title "RAG quality regression" \
  --service answer-api --environment staging
causepath incident add-evidence incident.json traces.json
causepath replay run reviewed-cases.jsonl --threshold 90
✦OPTIONAL BYO MODEL

CausePilot

causepilot

An opt-in assistant for incident explanations, reversible fix plans, and proposed regression cases. It uses a customer-selected OpenAI-compatible endpoint; a local model can be used through a local HTTPS-compatible gateway.

  • No model request runs without --allow-evidence-egress.
  • Known secret patterns are redacted before context is sent.
  • All output is a draft; CausePilot never executes commands or edits files.
export NORTHCAUSE_AI_BASE_URL="https://your-model-endpoint/v1"
export NORTHCAUSE_AI_API_KEY="..."
causepilot explain incident.json --evidence sample.log \
  --allow-evidence-egress
ONE INSTALL · TWO COMMANDS

Start in a virtual environment.

Install from the repository while the CLI package is in early access. The same package exposes both commands; choose the one that fits the task.

cd python-platform
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
causepath --help
causepilot --help
Safe defaults

CausePath is read-only toward production systems. CausePilot sends nothing until you explicitly allow evidence egress. Neither tool applies a remediation or deploys a change.

For CLI setup, command reference, environment variables, threat model, and limitations, read the CLI and portal guide ↗.
