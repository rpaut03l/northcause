OVERVIEW

Northcause turns operational evidence into reviewable investigations.

Upload incident context such as logs, deployment notes, RAG evaluations, GPU or Kubernetes events, and CI/CD output. Northcause organizes the evidence into a timeline, shows rule-based findings with source references, and lets a human record a review decision.

Evidence before confidence

Findings include references to source evidence. When the available material does not support an explanation, the result is marked as insufficient evidence.

Investigation workflow

  1. Create an incident. Record the affected service, environment, severity, and observed impact.
  2. Add evidence. Upload supported text-based files or connect an approved source.
  3. Review the timeline. Northcause normalizes timestamps and groups events for inspection.
  4. Assess findings. Run the local, deterministic rules analysis and review each finding against its source lines.
  5. Review a draft. A human approves or rejects suggested remediation with a reason.
  6. Verify after the change. New evidence can indicate whether the expected symptoms changed.

Evidence formats and handling

Text evidence can include .log, .txt, .json, .ndjson, .csv, and .yaml. File size and per-incident limits are enforced. Some common secret-like patterns are redacted before evidence is stored; uploads are size-limited and fingerprinted. Pattern-based redaction can miss sensitive values.

Security and model use

The current local pilot uses deterministic rules and does not send evidence to an external model. Evidence is stored in local SQLite-backed files. Apply deployment-specific storage, access, retention, and backup controls before using sensitive data.

Model output is advisory. Remediation remains draft-only and requires a human decision. Do not upload regulated or sensitive material unless your organization has approved the configured environment and data handling.

Integrations

The local pilot does not include live GitHub Actions, OpenTelemetry, or other telemetry connectors. Evidence can be added through supported text-file uploads; connector scope is agreed for each pilot.

API reference

The current local pilot does not expose a public integration API. Contact the team to discuss connector requirements for a scoped pilot.
