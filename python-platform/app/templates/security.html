SECURITY BY DESIGN

Make the evidence reviewable.
Keep decisions under your control.

The local pilot keeps analysis advisory: a human reviews findings and remediation drafts, and the application does not execute customer commands or production changes.

⌑
Human-reviewed operations

Recommendations are drafts. The pilot has no execution path for customer commands or system changes.

Default: advisory only
⌕

Evidence-bound claims

Claim citations are checked against the evidence currently stored for the incident. Unsupported claims are labeled clearly.

◈

Local rules analysis

The current pilot analyzes stored evidence with deterministic rules and makes no external model calls.

▤

Traceable decisions

Key account and incident actions are recorded in an audit view for review.

◉

Tenant boundaries

Each signed-in account can access only its own incident and evidence records in the local pilot. This is not a multi-tenant service.

⌁

Evidence hygiene

Text uploads are limited in size and common secret-like patterns are redacted. Pattern matching is not a complete secret detector.

⏱

Retention controls

The local pilot does not currently enforce an automatic retention schedule. Operators must manage local database and evidence-file retention.

Security posture is deployment-specific.

This local pilot is not a certified hosted service. It stores records on the local filesystem; review authentication, backups, access, encryption, and retention for your deployment before using sensitive data.
