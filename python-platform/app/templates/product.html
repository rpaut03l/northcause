Incident investigation

Build a time-aligned incident record from logs, traces, model activity, and deployment notes. Review findings against the source evidence.

  • Chronological event context
  • Source-linked rule findings
  • Explicit insufficient-evidence state
◇

RAG & agent evidence

Bring retrieval output, evaluation results, tool activity, and security signals into the same investigation for human review.

  • Grounding and citation evidence
  • Prompt-injection indicators
  • Tool and policy review context
▦

Infrastructure context

Relate AI behavior to the environment where it ran, including GPU, Linux, Kubernetes, and service evidence.

  • Development, staging, or production labels
  • GPU and cluster evidence files
  • Service and release context
✓

Review and verify

Record a proposed action, require a human decision, and attach follow-up evidence to check whether the expected change occurred.

  • Human-reviewed remediation drafts
  • Decision reason recorded
  • Follow-up evidence in the incident
