DESIGNED FOR OPERATOR CONTROL

Choose the session shape for the task.

Profiles can cover incident triage, evidence replay, and AI-assisted investigation. Proposed controls include ephemeral-by-default files, optional persistence, short-lived access, explicit model egress, and pre-launch usage estimates.

HOSTING DIRECTION

Start at the Cloudflare edge. Keep the runtime portable.

A future implementation can use a Worker as the authenticated session broker and Cloudflare Containers for isolated Linux CLI sessions. A portable container image and clear API boundary keep later migration to another compute provider possible.
