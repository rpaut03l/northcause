What this check measures

Exact-match accuracy for expected, baseline, and candidate strings. It does not judge semantic quality, safety, or whether a result is useful. Review the cases and add task-specific evaluators before using this as a production release gate.

Each line must be a JSON object with non-empty string fields: expected, baseline, and candidate. Payloads are scored in memory and are not saved.

INPUT FORMAT

One reviewed case per line

{"expected":"Answer cites the policy","baseline":"Answer cites the policy","candidate":"No citation included"}
{"expected":"Return the current limit","baseline":"Limit is 50","candidate":"Limit is 50"}

Use sanitized, approved examples. This local pilot does not ingest OpenTelemetry traces or call an external model.
